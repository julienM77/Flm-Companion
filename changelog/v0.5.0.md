## v0.5.0

### ✨ Added
- **Real-time resource monitoring**: Monitor NPU and RAM usage with live historical charts
  - Real-time RAM and NPU usage tracking with percentage and memory values
  - Historical charts (30 data points) showing resource trends over time
  - Start/Stop monitoring control to reduce CPU overhead when not needed
  - AMD NPU detection via Windows GPU Engine performance counters
  - Automatic display when server is running, configuration panel when stopped
  - Consistent UI design matching server logs panel
- **Server presets management**: Save, load, and manage custom server configurations as presets
  - Save current server configuration (model, performance mode, ASR, embeddings, CORS, etc.) as a preset
  - Manage presets dialog to view and delete user-created presets
  - System presets (Low Power, Balanced, Performance) available alongside user presets
  - Presets accessible from server view dropdown menu and system tray with visual distinction
  - Persistent storage of user presets in application configuration
  - Preset menu hidden when server is running to prevent configuration changes
- Simplified models menu in the system tray (single submenu for easier selection)
- Toast notifications inside the app (shown also when window is closed)
- Automatic update check on application startup for both Companion and FLM
- Update dialogs for FLM and Companion with download progress
- FLM changelog display in About view
- "No models available" message in tray menu when no models are ready
- GitHub API rate limiting handling with 5-minute cache to prevent 403 errors

### 🐞 Fixed
- Fixed FLM version update bug in the app after installing a new program version
- Fixed FLM changelog not displaying due to version format mismatch (v prefix)
- Fixed update dialog not closing after FLM installation completion
- Fixed version display not refreshing after FLM update
- Fixed NPU usage values clamped to 0-100% range to prevent display issues

### 🎨 Improved
- Updated model tags visuals and added a warning for models that are too large for the running machine
- Enhanced startup checks with better error handling and logging
- Improved GitHub API integration with retry logic for different tag formats
- Immediate UI feedback when starting server (switches to resource monitor instantly)
- System tray menu now disables presets, models, and features selection when server is running
- Consistent styling between resource monitor and server logs panels

### 📦 Dependencies
- Updated all npm packages to latest versions (React 19.2.5, Vite 8.0.8, TypeScript 6.0.3, TailwindCSS 4.2.2, i18next 26.0.5, Recharts 3.8.1, Sonner 2.0.7, Lucide React 1.8.0)
- Updated Tauri API and all plugins to latest versions (@tauri-apps/api 2.10.1, dialog 2.7.0, fs 2.5.0, http 2.5.8, shell 2.3.5, notification 2.3.3, autostart 2.5.1, opener 2.5.3, os 2.3.2, process 2.3.1)
- Synchronized Rust and NPM package versions for Tauri plugins

### 🔄 Updated
- Minimum required FLM version bumped to **0.9.37**
- Model list detection now checks `%USERPROFILE%\.flm\` first (new FLM default since 0.9.37), with fallback to `C:\Program Files\flm\`
